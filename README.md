# AI/ML From Scratch

A self-study journey through the programming foundations of AI and machine
learning. The goal is to learn concepts step by step, implement examples, and
keep the work and progress visible.

> **Current focus:** the repository currently contains beginner Python exercises
> on fundamentals, functions, and data structures. It is a learning log, not yet
> a machine-learning library or a collection of AI/ML implementations.

## Start here

You only need Python 3 to run the `.py` exercises. There are no third-party
packages to install.

1. Clone the repository and open its directory:

   ```bash
   git clone https://github.com/ezxrohitkumar-cloud/AI-ML-From-Scratch.git
   cd AI-ML-From-Scratch
   ```

2. Run a script from the repository root:

   ```bash
   python hello.py
   ```

   On Windows, `py -3 hello.py` is another way to select Python 3; on
   macOS/Linux, use `python3 hello.py` if `python` does not point to Python 3.

3. Try an interactive exercise, for example:

   ```bash
   python evenodd.py
   ```

   Follow the prompt in the terminal. Each exercise is a standalone script, so
   run it individually rather than expecting a single application entry point.
