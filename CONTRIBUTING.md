# Contributing

Thanks for helping improve this learning repository. Small, focused
contributions are easiest to review and learn from.

## Propose a change

1. Open an issue to suggest a topic or describe a larger change. For a small
   correction or self-contained exercise, you can open a pull request directly.
2. Fork the repository and create a branch for your change.
3. Keep new exercises as standalone Python files in the repository root, in
   keeping with the current layout. Use a descriptive filename and a short
   explanation of what the exercise demonstrates.
4. Run the script with Python 3 and check that its prompts and output are clear.
   For an exercise that expects input, try a representative input before
   submitting.
5. Open a pull request describing what changed, why it is useful, and how you
   tried it.

There is no automated test suite or required formatter at present. Avoid adding
dependencies for a small exercise unless they are needed and explained.
